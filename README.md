# FC 27 Dynamic OVR Disabler

Standalone open-source Windows desktop utility developed to neutralize temporary Dynamic Overall (OVR) modifiers in EA SPORTS FC 27 offline Career Mode.

## Features
- **Form Modifiers Neutralization**: Disables temporary attribute boosts and penalties caused by player form.
- **Morale Modifiers Neutralization**: Disables temporary attribute boosts and penalties caused by player morale.
- **Match Fitness Modifiers Neutralization**: Disables temporary match fitness attribute scaling.
- **Architectural Preservation**:
  - Preserves natural player growth and development curves.
  - Preserves age-related player attribute regression.
  - Preserves original injury penalties (Yellow: -30, Red/Orange: -80).
  - Preserves fitness thresholds and category definitions.
  - Preserves form and morale weight configurations.
- **Safety & Integrity**:
  - Automatic timestamped backups with SHA-256 verification.
  - Reversible and idempotent transformations.
  - Non-invasive: No DLL injection, memory patching, or anticheat tampering.

## Installation & Usage
Run the standalone executable:
`publish/FC27-Dynamic-OVR-Disabler-v0.1.0-alpha-win-x64/OVRDisabler.App.exe`
